# kb list

List all knowledge base entries

## Usage

```bash
aux4 kb list [--folder <folder>]
```

## Variables

- `--folder` (default: `.knowledge`) - Knowledge base folder path

## Description

Outputs the knowledge base index as a markdown table showing topic, file, tags, date, and summary for each entry.

## Examples

```bash
aux4 kb list
```

```bash
aux4 kb list --folder my-notes
```
