# kb view

View a knowledge base entry

## Usage

```bash
aux4 kb view "<topic>" [--folder <folder>]
```

## Variables

- `topic` (required) - Topic title
- `--folder` (default: `.knowledge`) - Knowledge base folder path

## Description

Outputs the full markdown content of a knowledge base entry.

## Examples

```bash
aux4 kb view "Docker Networking"
```
